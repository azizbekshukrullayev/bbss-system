# BBSS Platform Prototype

Bu papkada BBSS Platform 1.0 ning mustaqil frontend prototipi saqlanadi.

## Fayllar
- `index.html` — CSS va JavaScript ichiga joylangan yagona sayt fayli. Alohida asset papkalari talab qilinmaydi.

## Ishga tushirish
`index.html` faylini brauzerda oching yoki papkani statik hostingga joylang.

## Live demo
https://bbss-platform-prototype.vercel.app

## Muhim eslatma
Bu frontend demo. Haqiqiy autentifikatsiya, server-side rollar, ma'lumotlar bazasi, real-time chat va AI Gateway alohida backend integratsiyasini talab qiladi.
